# 保全排班工具

自動化保全人員月排班系統，解決手動 Excel 排班耗時且難以兼顧所有規則的問題。

**[→ 線上展示](https://basil-guard-scheduler.vercel.app)**

---

## 背景

這個工具源自真實需求：司法院的保全人員長期用 Excel 手工排班，每個月要花大量時間在確認規則（連續上班天數、哨點輪替、假日交替、時數平衡），且容易出錯。

本專案的目標是把這個流程自動化：輸入人員和假日資料，一鍵產生符合所有規則的排班，並即時顯示違規。

---

## 功能

- **自動排班**：依配額演算法分配哨點，確保每人每月的哨點次數與時數平均
- **規則驗證**：即時檢查 6 條排班規則，違規欄位標紅並顯示原因
- **颱風假**：一鍵套用颱風假模式（取消平日哨點，D/E 人員改派 F/G），可還原
- **假日同步**：自動從政府資料來源抓取當年國定假日
- **班別統計**：每人每月各哨點次數與總時數一覽

---

## 排班規則

| # | 規則 |
|---|------|
| 1 | 不超過連續 6 天上班 |
| 2 | 不重複相鄰哨點（同一哨點不連兩天） |
| 3 | 假日星期交替（六↔日） |
| 4 | 假日哨點交替（F↔G） |
| 5 | 每人月總時數差距 ≤12h |
| 6 | 每個哨點分配差距 ≤1 次 |

**哨點設定**

| 哨點 | 類型 | 時數 |
|------|------|------|
| A / B / C | 平日 | 10h |
| D / E | 平日 | 12h |
| F / G | 假日 | 12h |
